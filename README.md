# Finley Holt

Visiting Scholar in the [Autonomous Systems Laboratory](http://asl.stanford.edu/), Department of Aeronautics and Astronautics, Stanford University, and a second lieutenant in the U.S. Marine Corps. I build agentic systems for robotics and autonomous aircraft, and I work on the safety of agents that act on physical systems.

## Publications

**Structured World-State Reasoning for Agentic Robotic Search**<br>
F. Holt, L. Pabon, J. Alora, J. Frey, M. Pavone. Under review, IEEE International Conference on Robotics and Automation (ICRA) 2027.<br>
[arXiv:2609.23841](https://arxiv.org/abs/2609.23841)

WORLDS, an agent that finds an object described in plain language by reasoning over a structured world state built from maps and onboard imagery. State of the art on the CityNav aerial benchmark: 51.8% success over all 5,311 test episodes, 15.7 points above the prior best. Demonstrated on a custom quadcopter.

## Research

- **HAVE WORLDS** (2026). Technical lead for an Air Force Test Pilot School Test Management Project: the first flight test of semantic-based robotic search for search and rescue, flown at Edwards Air Force Base in September 2026.
- **Aviation safety** (2026 to present). Agentic safety evaluation and monitoring for the Autonomous Systems Laboratory's NASA University Leadership Initiative project on aviation safety.
- **FAIRshake** (M.S. thesis, Case Western Reserve University, 2025). A framework for automating high-throughput X-ray diffraction data processing and machine learning integration. [cwru-sdle/FAIRshake](https://github.com/cwru-sdle/FAIRshake)
- **MIT Lincoln Laboratory** (2025). Automation engine for a continual-learning training-data pipeline for computational fluid dynamics, run on idle supercomputer capacity: peaked at 6.4x the standard compute allocation, with over 99% of 5,164 simulations completing.
